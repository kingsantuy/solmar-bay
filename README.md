Solmar Bay is a 3D open-world crime game — a make.fun gta6-01 "Make GTA 6" entry. Play Rook Reyes, a driver-for-hire in a sun-soaked coastal city: eight story jobs for the crew, carjacking, a five-star wanted level with police dispatch, helicopter and roadblocks, a weapon wheel, respect ranks, garage upgrades, taxi fares, synth radio and saves — all in the browser, offline, no downloads.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080

## Controls

- WASD / arrows — move and drive, Shift — run
- E — enter / exit car, Space — handbrake, F — punch
- 1–5 — weapons, Q — weapon wheel, G — garage at the Chop Shop
- Esc / P — pause, M — mute, R — radio, mouse click — shoot
